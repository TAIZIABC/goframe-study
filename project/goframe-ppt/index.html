Before / After

为什么不只用 Gin？

Before · 传统组合

Gin + GORM + Viper + ...

  • HTTP 框架只管路由，其它全靠自选
  • 日志 / 配置 / ORM / 缓存各自为政
  • 工程规范无统一标准
  • 代码生成靠第三方，链路追踪要自己接
After · GoFrame

一站式企业框架

  • HTTP / ORM / 日志 / 配置 / 缓存统一内置
  • gf 脚手架生成 DAO / Service / Controller
  • 规范路由 + 自动参数校验 + OpenAPI 文档
  • ctx 贯穿全链路追踪，开箱即用

Quick Start · 上手指南
09 / 10
3 Steps to Start

三步开始

From Zero to Running · 从零到运行
01
安装 CLI
go install github.com/gogf/gf/cmd/gf/v2@latest
验证：gf -v
02
初始化项目
gf init my-project
自动生成标准目录结构 + 配置文件
03
热编译运行
cd my-project && gf run main.go
浏览器访问 :8000/swagger 查看 API 文档
规范路由签名：func(ctx context.Context, req *XxxReq) (res *XxxRes, err error)
框架自动绑定路由、解析参数、做校验、格式化响应 —— 你只需要写业务逻辑。
— GoFrame 规范路由核心约定
